# 老黄的后花园

一方自己的小院：想说什么，就种下一句。

一个只用 **HTML + CSS + JavaScript** 写成的极简发布小站，没有框架、没有构建步骤、没有服务端，所有内容保存在你自己的浏览器 `localStorage` 里。

## 功能

- **发布**：填写署名（留空记为「花园访客」）+ 正文（1–500 字），点「种下这条」或按 `Ctrl / ⌘ + Enter` 提交；实时字数计数，超过 500 字自动禁用提交。
- **查看**：按发布时间倒序展示，包含头像首字、署名、相对时间（刚刚 / N 分钟前 / 今日时分 / 月日时分）与正文，正文保留换行。
- **点赞**：每条可点赞 / 取消点赞，状态写入本地存储，刷新后仍在。
- **删除**：二次确认后删除，列表与本地存储同步移除。
- **筛选**：顶部搜索框对正文与署名做大小写不敏感匹配，实时过滤并显示「共 N 条 · 命中 M 条」，命中文字高亮，可一键清除（或按 `Esc`）。
- **容错**：存储被禁用、数据损坏、空间已满都有明确提示；「一条都没有」与「没搜到」是两种不同空态。

## 运行方式

方式一：直接双击 `index.html`，用浏览器打开即可。

方式二（推荐，行为与线上一致）：在本目录起一个静态服务。

```bash
python -m http.server 8123
# 然后访问 http://localhost:8123/
```

## 数据存储

| 键名 | 内容 |
| --- | --- |
| `lyd.posts.v1` | 所有动态的 JSON 数组 |
| `lyd.author.v1` | 上次使用的署名 |

单条记录结构：

```json
{
  "id": "m3k9x2ab",
  "author": "老黄",
  "content": "院子里第一句话",
  "createdAt": 1763000000000,
  "liked": false
}
```

- 数据只存在于当前浏览器、当前域名下；清除站点数据、换浏览器或换设备都不会同步。
- 数据可被手工修改，因此读取时会做类型校验与字段裁剪，异常时降级为空列表并提示。
- 写入失败（如本地空间已满）时不改动界面，避免「看起来发出去了其实没存住」。
- 多个标签页同时打开时，任意一页写入会让其他页自动刷新列表。

## 实现要点

- 所有用户输入通过 `textContent` 写入 DOM，不拼接 `innerHTML`，从根上避免脚本注入；筛选高亮也只插入文本节点与 `<mark>`。
- 发布 / 删除 / 筛选后整体重绘列表（`DocumentFragment` 一次性插入），状态绝对一致；点赞属高频轻交互，只做局部更新，不重建卡片。
- 写入顺序永远是「先落盘、成功后才改内存与界面」，失败即回滚提示。
- 列表事件用事件委托挂在容器上，只绑定一次。
- 筛选输入用 `requestAnimationFrame` 合并同一帧内的连续输入，无需防抖计时器。
- 尊重 `prefers-reduced-motion`：关闭动效时删除立即生效。
